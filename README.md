# Hackatón ADSO 2026

Este proyecto es una página web sobre la Hackatón ADSO 2026.

## Descripción

La página muestra información del evento.

## Agenda

- Actividades del evento.
- Horarios de las actividades.

## Inscripción

Información para participar en la Hackatón.

## Ubicación

Dirección y mapa del evento.

## Tecnologías

- HTML
- CSS
- Git
- GitHub

## Ejemplo de código

```html
<h1>Hackatón ADSO 2026</h1>
```

## Enlaces

[GitHub](https://github.com/)


## Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Abre el archivo `index.html` en tu navegador.
4. Usa el menú para consultar la agenda, la inscripción y la ubicación del evento.

## Estado del proyecto

El proyecto contiene la información principal de la Hackatón ADSO 2026 y permite navegar entre sus secciones.
